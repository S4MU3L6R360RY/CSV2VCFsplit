# CSV to VCF Converter

A simple Windows desktop application for converting CSV contact lists into multiple VCF files.

## Features

- Simple graphical user interface
- Select CSV using a file browser
- Enter a custom token
- Specify the number of VCF files
- Automatically distribute contacts between files
- Global contact numbering
- vCard 3.0 output
- No command-line interaction required
- Can be packaged as a standalone Windows executable
